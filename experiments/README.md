# VITO Experiments

Every VITO training run receives a unique experiment identifier.

## Experiment naming

VITO-EXP-001
VITO-EXP-002
VITO-EXP-003

Each experiment records:

- model configuration
- tokenizer configuration
- dataset version
- random seed
- optimizer
- learning rate
- batch size
- gradient accumulation
- training tokens
- hardware
- training duration
- validation loss
- perplexity
- generated samples
- observations
